# Plan

Follow the references below only as needed; never upfront.

- ./plan-mode.md - when working in Plan (Plan tabs, not a mode, see ../007-editor/editor-modes.md): adding a Plan tab, its palette, its templates, collaboration, agents and telemetry
- ./plan-tabs.md - when working on the Plan tab kinds (Board, Sheet and Dashboard tabs): what each holds, Dashboard slots, metric tiles, figures from a Sheet, export, converting old Plan tabs
- ./plan-templates.md - when working on the Plan templates: the catalogue, the tabs each makes, hand-offs between their boards
- ./plan-board.md - when working on the Plan board or Plan card elements: board set-up, columns, swimlanes, WIP limits, card faces, dragging, the item panel, voting, hide writing, CSV import and download
- ./board-widgets.md - when working on a Plan board's header: its widgets, the Widgets palette category, placing, reordering and removing widgets
- ./plan-views.md - when working on plan views: metrics and visualisations (Gantt, calendar, workload, status, priority) that read every card
- ./item-types.md - when working on item types: the type catalogue, custom types and custom fields, the Card Types panel and the type editor
- ./plan-tour.md - when working on the Plan tour: the guided tour of the Plan tabs, on the actions group's Start Tour button once a board or Sheet is open and run on it, its Boards and Sheets tracks, the Dashboards tour, its Settings row and telemetry
- ./plan-agents.md - when working on how agents (MCP, CLI) read the plan, name columns, types and fields, and change card types
- ./linked-boards.md - when working on linked boards: the Actions board that collects every action, linked cards kept in step with the canvas, Won't Do
- ./items.md - when working on items and the item store: fields, item types, writes, access, live sync, undo, offline documents, copies, limits
- ./blueprints/README.md - when implementing Plan tabs, the Plan board or the item store: file-level contracts, constants, defaults and tests
