# Wikis

Follow the references below only as needed; never upfront.

A **wiki** is a folder of pages read together: opened from an entry page, linked page to page, searched as one. A
global wiki syncs to a repository of its own; a project wiki to a path inside a project's repository.

- ./wiki.md - when working on wikis: what makes a folder one, global and project wikis, sync targets, what is mirrored, the entry page, wiki health (orphan pages, broken links), search, share roles, privacy
- ./links.md - when working on links between pages: link forms, links across wikis, renames that rewrite links, links out of the wiki, broken links, backlinks
