# Information security

Follow the references below only as needed; never upfront.

LiveDoc runs an information security management system (ISMS) aligned with ISO/IEC 27001:2022, without certification.

- ./isms.md - when asking what the ISMS covers, who owns it, its policy, objectives, records and review cadence
- ./assets.md - when adding or retiring a data store, supplier, domain, operator account or secret
- ./risk-register.md - when a change adds, removes or shifts a security risk, or at the yearly review
- ./statement-of-applicability.md - when asking whether and how an ISO 27001 Annex A control is met
