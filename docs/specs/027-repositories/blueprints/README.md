# Repositories blueprints

Follow the references below only as needed; never upfront.

- ./repository-link.md - when building the first slice of repository links: `livedoc.toml`, mirror levels, `INDEX.md`, mirror and outline files, sync states, the lock and local sync state, `sync --watch`, `link init|status|ls`
- ./local-copy.md - when building the local copy: a link without git, native files both ways, records, bases, the text merge, adoption, moves and deletes, the folder-missing guard, `sync --watch` on a copy folder, `sync --take`
- ./DEFAULTS.md - when a blueprint here applies a default the spec leaves open
- ./COMPLETENESS.md - when checking which completeness categories a blueprint here covers
