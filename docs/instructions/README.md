# Instructions

Follow the references below only as needed; never upfront.

Instruction sets are reusable process memory: how a process is done, step by step, in the order it is actually done.

- ./compare-drawio-imports.md - when checking how draw.io files look after the import
- ./evaluate-mcp-output.md - when measuring or raising the quality of what an assistant makes through the MCP server
- ./gate-a-feature-by-share-role.md - when specifying or building anything a shared document can reach (Editor, Participant, Viewer)
- ./register-a-help-article.md - when adding, removing, or renaming a help-centre article
- ./respond-to-a-security-incident.md - when a security event is seen: a report, an alert, a leak, an outage
- ./review-operator-access.md - when the quarterly access review is due: operator accounts, tokens, the main ruleset, devices
- ./review-suppliers.md - when the yearly supplier review is due, or before adding a supplier that receives data
- ./run-the-isms-review.md - when the yearly ISMS management review is due
- ./test-a-restore.md - when the 6-monthly restore test is due, or data must be brought back to an earlier minute
- ./trace-a-canvas-gesture.md - when measuring what a click, drag or pan costs on a large board
- ./verify-a-tab-export.md - when checking what Export really produces for a tab kind or element (images, JSON, Markdown)
