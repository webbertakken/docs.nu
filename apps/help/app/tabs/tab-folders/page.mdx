When a document's [tab list](/help/user-interface/tab-bar/) grows long, a flat list of tabs gets hard to scan. A **tab folder** gathers related tabs under one named heading. Put three tabs under "Organisation" and two under "Plans", and the list stays calm however many tabs each folder holds.

## How folders work

A few things are worth knowing about how tab folders behave:

- **One level.** A folder holds tabs. Folders never contain other folders.
- **A folder is just a name.** There is no separate folder object to create or delete. A folder exists as long as at least one tab carries its name, and it disappears when the last tab leaves it.
- **Per-document.** If a tab is [shared into more than one document](/help/tabs/add-to-document/), it can sit in a folder in one document and be loose in another. The folder belongs to the document, not to the tab's content.
- **Folders are contiguous.** A folder's tabs always sit together in the tab order, under a single heading with a folder icon, the folder's name and a count of its tabs.
- **Shared with collaborators.** Folder names and membership are part of the document, so everyone sees the same folders.

## Folders in the tab list

Open the tab list from the tab stack (or the people here) at the bottom right, and each folder is a heading with its tabs indented under it:

- **Click a tab** under a heading to switch to it; the list closes.
- **The tab you are on stays visible.** When the active tab lives in a folder, its row is tinted under the folder's heading, and the active tab at the bottom right names it, so you can always see where you are.
- **Presence comes along.** Each tab's row shows the avatars of the collaborators on it, inside a folder as anywhere else.

## Putting tabs in folders

There are two ways to change which folder a tab belongs to.

<Step n={1}>
  Drag and drop. Drag a tab's row onto a folder's tabs (or onto its heading, which files it at the
  front of the folder) to join that folder. Drop it among the loose tabs to make it loose again, or
  among a different folder's tabs to move it there.
</Step>

<Step n={2}>
  The tab menu. Open the tab's **⋯** or right-click menu and choose **Add to Folder**. In the
  dialog, pick an existing folder's tile to file the tab there, the **No Folder** tile to make it
  loose in the list, or the **New Folder** tile to type a fresh name in place. Typing an existing
  folder's name simply files the tab into that folder, since same name means same folder.
</Step>

<Figure caption="Add to Folder opens a dialog with a No Folder tile, a tile per folder (the current one marked), and a New Folder tile.">

</Figure>

## Renaming a folder

**Double-click the folder's heading** in the tab list to rename the folder. Renaming rewrites the name on every tab in it, so the folder keeps all its tabs. Renaming it to another folder's name merges the two.

To get rid of a folder, move its tabs out (drag them to the loose tabs, or choose **No Folder**): the folder disappears with its last tab. Its tabs are never deleted.

On a share link for a Viewer or a Participant, or a link scoped to one tab, you can see folders and switch tabs, but you can't drag tabs between folders or rename them.

<Tip>
  Give folders short names like "Plans" or "Back office". The name shows on the heading with a
  count, so a tight name keeps the tab list readable.
</Tip>
